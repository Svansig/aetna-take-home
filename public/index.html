Movie Services API

A read-only TypeScript and Express API over the two supplied SQLite databases, movies.db and ratings.db, which are used unmodified.

Open the API docs View on GitHub

User stories

All four user stories from the brief are implemented under /api/v1. Each example link below calls the live API.

Story Endpoint Example
List all movies GET /api/v1/movies /api/v1/movies
Movie details GET /api/v1/movies/{movieId} /api/v1/movies/11
Movies by year GET /api/v1/movies/year/{year} /api/v1/movies/year/1999
Movies by genre GET /api/v1/movies/genre/{genre} /api/v1/movies/genre/Action

Listings return 50 movies per page (?page=2), accept sortOrder=asc|desc, and /api/v1/movies can combine year and genre filters, for example ?year=1999&genre=Action.

Known data limitation

Average ratings may belong to a different movie. The movies database uses TMDB ids and the ratings database uses MovieLens ids, and ratings are matched by the raw number. The data is served as supplied, without repair. See the documented assumptions.
